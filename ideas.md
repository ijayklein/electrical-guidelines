<idea>
**Design Movement:** Technical Blueprint / Engineering Documentation

**Core Principles:**
1. Information density with clarity — every pixel serves a purpose
2. Grid-based precision with deliberate asymmetry in layout sections
3. Dark, authoritative background with high-contrast accent colors
4. Data visualization as the primary communication vehicle

**Color Philosophy:**
Deep navy/charcoal base (#0F172A, #1E293B) evoking electrical schematics and technical manuals. Electric amber (#F59E0B) as primary accent for warnings and highlights, recalling caution tape and electrical hazard symbols. Cool slate (#94A3B8) for secondary text. Bright cyan (#06B6D4) for interactive elements.

**Layout Paradigm:**
Left sidebar navigation (sticky) with main content area using a 2/3 + 1/3 split. Sections break out of the grid with full-bleed chart panels. Content flows vertically with horizontal rule separators styled as circuit traces.

**Signature Elements:**
1. Circuit trace decorative lines connecting section headers
2. Electrical symbol icons (outlet, switch, fixture) as section markers
3. Warning badges styled like electrical hazard labels

**Interaction Philosophy:**
Hover states reveal additional code citations. Tabs for switching between floor plan quality levels. Accordion sections for detailed code text.

**Animation:**
Subtle fade-in on scroll. Circuit trace lines draw themselves on page load. Chart bars animate in sequence.

**Typography System:**
IBM Plex Mono for headings and code references (technical authority). IBM Plex Sans for body text (readable, professional). Tight letter-spacing on headings.
</idea>

<idea>
**Design Movement:** Clean Professional Reference Manual / Swiss Design

**Core Principles:**
1. Structured hierarchy through typography alone, not decoration
2. Generous whitespace with strict alignment grids
3. Color used sparingly as a functional signal, not decoration
4. Tables and charts as primary content — not supplementary

**Color Philosophy:**
Warm white background (#FAFAF9) with near-black text (#1C1917) for maximum readability. A single accent color — deep electrical blue (#1D4ED8) — used only for interactive elements, links, and key data points. Muted amber (#D97706) reserved exclusively for warnings and code requirements. No gradients.

**Layout Paradigm:**
Asymmetric: a persistent left sidebar (fixed, 260px) with a main content area. Content sections use a magazine-style layout with alternating full-width and 2-column arrangements. Charts and tables break into full-width panels with a subtle background tint.

**Signature Elements:**
1. Bold section numbers in a large, light-weight display font
2. Colored left-border accent on code requirement callouts
3. Compact data tables with alternating row shading

**Interaction Philosophy:**
Room-type tabs at the top of the main content area. Smooth scroll navigation from sidebar. Tooltip overlays on chart data points showing exact NEC code references.

**Animation:**
Minimal — only smooth scroll and subtle fade-in for section content. Charts animate once on first viewport entry.

**Typography System:**
Playfair Display for main section titles (editorial authority). Source Sans Pro for body and UI text (clean, legible). Courier New for NEC code citations (monospace authenticity).
</idea>

<idea>
**Design Movement:** Industrial Modernism / Construction Documentation

**Core Principles:**
1. Bold, utilitarian aesthetic that communicates authority and practicality
2. Heavy typographic hierarchy — section headers dominate the visual weight
3. Structured data presentation with interactive filtering
4. Color coding as a primary navigation and comprehension tool

**Color Philosophy:**
Off-white background (#F5F0EB, slightly warm) to avoid sterile clinical feel. Deep charcoal (#292524) for text. A rich, warm amber (#B45309) as the primary brand color — evoking copper wire and electrical components. Muted green (#15803D) for "safe/compliant" indicators. Red (#DC2626) for warnings and prohibited zones.

**Layout Paradigm:**
Full-width header with a sticky top navigation bar. Content divided into tabbed sections by room type. Each room section uses a 3-column card grid for quick scanning, with expandable detail panels. A sticky "quick reference" panel floats on the right side of the screen on desktop.

**Signature Elements:**
1. Color-coded room type badges (kitchen=amber, bathroom=blue, bedroom=green, etc.)
2. Horizontal progress/compliance bars showing code requirement density
3. Interactive floor plan diagram showing outlet placement zones

**Interaction Philosophy:**
Room-type filter tabs. Expandable accordion cards for detailed code text. A "floor plan quality" slider that changes the displayed guidance level. Hover states on charts reveal NEC code section numbers.

**Animation:**
Entrance animations for cards on scroll. Smooth tab transitions. Chart bars grow from zero on first view.

**Typography System:**
Barlow Condensed for section headers (bold, industrial, space-efficient). Lato for body text (neutral, highly readable). Monospace for NEC code references.
</idea>
<text>Industrial Modernism — warm off-white, copper/amber brand color, color-coded room system, bold condensed typography</text>
